ML-Paradigmen

Machine Learning lernt aus Daten statt aus festen Regeln. Wie ein System lernt, unterscheidet sich in drei Paradigmen — und innerhalb von Supervised Learning gibt es zwei Grundformen: eine Kategorie vorhersagen oder einen Zahlwert.

0 / 5 Aufgaben

Die drei Paradigmen des Machine Learning

Die wichtigste erste Frage bei jeder Anwendung: Habe ich Labels? Labels sind die „richtigen Antworten“, die das Modell beim Lernen kennen darf. Je nachdem, wie das Modell lernt, spricht man von drei Paradigmen.

Supervised · Unsupervised · Reinforcement

Supervised — lernt aus gelabelten Daten (Eingabe → bekannte Ausgabe). Der grösste Teil aller Anwendungen.

Unsupervised — findet Struktur ohne Labels, z. B. Kundengruppen (Clustering).

Reinforcement — lernt durch Belohnung/Bestrafung in einer Umgebung (Roboter, Agenten).

Drill-in · Self-Supervised: Eigentlich keine Algorithmenfamilie, sondern eine Technik — das Modell erstellt sich selbst „Rätsel“ (z. B. ein Wort im Satz wegnehmen und es erraten). Deshalb können grosse Sprachmodelle aus riesigen unbeschrifteten Textmengen lernen. Kosteneffizient & skalierbar.

Klassifikation oder Regression?

Innerhalb von Supervised Learning gibt es zwei Grundformen: eine Kategorie vorhersagen (Klassifikation) oder einen Zahlwert (Regression). Die Antwort entscheidet über die Wahl von Algorithmen und Metriken.

Die Unterscheidung

Klassifikation — diskrete Klassen: ja/nein, Kundenkategorie, Betrug/kein Betrug.

Regression — kontinuierlicher Zahlwert: Preis in CHF, verkaufte Einheiten, Temperatur.

Drill-in · Schnelle Heuristik: Kann die Antwort „nein“ oder „Standard“ sein? → Klassifikation. Muss die Antwort eine Zahl sein, die beliebig fein sein darf? → Regression. Logistische Regression klingt nach Regression, ist aber Klassifikation (sie liefert ja/nein-Wahrscheinlichkeiten).

Die Algorithmus-Galerie

Es gibt viele Algorithmen. Für das Management reicht es, die Familien zu kennen und zu wissen, wann welche typischerweise passt — das Detail übernimmt das Data-Science-Team.

Die wichtigsten Familien

Lineare Regression — eine Trendlinie durch die Daten (Zahlwert vorhersagen).

Entscheidungsbäume — if-then-Regeln, sehr interpretierbar.

Ensembles — viele Bäume zusammen: Random Forest (Mehrheitsentscheid) & Gradient Boosting (Stafette, jeder Baum korrigiert den letzten).

Support Vector Machines — finden die beste Trennlinie zwischen Klassen.

Deep Learning — neuronale Netze; stark bei Bildern, Sprache und grossen Datensätzen.

Drill-in · Warum Ensembles? Ein einzelner Baum macht Fehler. Ein „Wald“ aus vielen, leicht unterschiedlichen Bäumen gleicht diese aus — die „Weisheit der Masse“. Genau deshalb sind Random Forest & Gradient Boosting in der Praxis oft die erste Wahl bei tabellarischen Daten.
